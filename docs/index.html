Hero

Internacionalização

Uma página, três idiomas, duas direções

O consultório atende pacientes brasileiros, de língua inglesa e israelenses. O tema troca o idioma pelo seletor do cabeçalho e, em hebraico, espelha o layout inteiro com dir="rtl" e propriedades lógicas de CSS.

drrafaelsukiennik · /?lang=pt

Seletor de idioma no canto do cabeçalho. Sem plugin de tradução: um dicionário em inc/i18n.php.

Engenharia

Tema sob medida

  • Templates PHP separados por seção em template-parts/
  • CSS puro com tokens, mobile-first, ~1.000 linhas
  • Ícones SVG inline que herdam currentColor
  • Ambiente local com Docker: WordPress, MySQL e WP-CLI

SEO técnico

  • Meta description, Open Graph e Twitter Card
  • JSON-LD schema.org/Physician na home
  • Sitemap XML nativo do WordPress
  • lang e dir corretos por idioma

Segurança

  • Editor de arquivos do painel desativado
  • XML-RPC desligado e versão do WP oculta
  • Usuários protegidos: REST API, páginas de autor e sitemap
  • Cabeçalhos de segurança HTTP enviados pelo tema

Acessibilidade

  • Foco visível em dourado em todos os controles
  • aria-expanded no menu mobile e no seletor de idioma
  • Respeita prefers-reduced-motion
  • Seletor de idioma fecha com Esc ou clique fora
